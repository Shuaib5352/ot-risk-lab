# Third-party and public-reference notice

OT-RiskLab's implementation is original to this repository. No third-party source code is vendored in the core package.

Public resources reviewed or referenced include:

- NIST Cybersecurity Framework 2.0;
- NIST SP 800-82 Rev. 3;
- MITRE ATT&CK for ICS and MITRE Center for Threat-Informed Defense Attack Flow as prior-art context;
- FIRST Exploit Prediction Scoring System documentation;
- CISA Known Exploited Vulnerabilities Catalog documentation.

These resources inform terminology, evidence handling, threat context, and design decisions. OT-RiskLab does not claim endorsement, certification, or conformance by those organizations.

No ATT&CK, EPSS, KEV, or Attack Flow source code/data is bundled into the core package by default.
