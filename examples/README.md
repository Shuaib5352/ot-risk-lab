# Examples

These files are demonstrations, not empirical site assessments.

- `demo_config.json` — full single-scenario example.
- `before_controls.json` / `after_controls.json` — control-comparison example.
- `scenarios/` — small portfolio for batch and risk-register commands.
- `benchmark_suite.json` — approved computational reference values used to detect unintended numerical drift.
- `calibration_template.csv` — empty template for independently observed binary outcomes.
- `study_observations.csv` — synthetic multi-site/time example for bootstrap and held-out study diagnostics.
- `analyst_ratings.csv` — synthetic analyst-rating example for inter-rater agreement.

Do not treat the example risk values, control effectiveness values, or tolerance as organizational recommendations. Replace them with documented site-specific assumptions and evidence.
